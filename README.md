# Nail n Lash Studio & Academy — Luxury Website

A high-converting, luxury web application and digital presence for **Nail n Lash Studio & Academy LLP**, located in Phase 10, Sector 64, Mohali (SAS Nagar), Punjab — serving the entire Chandigarh Tricity region (Mohali, Chandigarh, Panchkula).

---

## 💎 Design Philosophy & Highlights
- **Editorial Luxury Aesthetic**: Styled with Cormorant Garamond serif typography, champagne gold gradients, warm sand/linen canvas (`#FAF8F5`), and dark charcoal surfaces.
- **Concise & Non-Bloated**: Designed specifically to avoid endless sprawling text walls. Uses tabbed category selectors for 60+ salon treatments, curated signature highlights, and dedicated academy cards.
- **Interactive WhatsApp Booking Flow**: Pre-configured WhatsApp booking generator directing leads instantly to `+91 84275 20007` with structured date, slot, client details, and treatment notes.
- **Academy Inquiry Engine**: Dedicated modal for students seeking ISO-certified masterclasses in Nail Extensions, Eyelash Artistry, and Permanent Make-up / Microblading.
- **Dynamic Operating Status**: Automatically calculates whether the salon is currently Open (10:00 AM – 7:30 PM) or Closed, rendering a live indicator pill.
- **Google Social Proof**: Displays verified 4.5★ rating proof from 210+ Google Reviews with real customer testimonials.
- **Google Maps & Directions**: Embedded map of Phase 10 Sector 64 Mohali with 1-click address copy and instant directions.

## 🚀 How to Run Locally

### Option 1: Direct Browser Launch
Simply double-click `index.html` in your file explorer, or right-click and choose **Open with > Chrome / Edge / Firefox**.

### Option 2: Local Python Server
Open a terminal in the project directory and run:
```bash
python -m http.server 3000
```
Then visit: [http://localhost:3000](http://localhost:3000)

## 🌐 Deploy to Production
This website is 100% static, fast, and dependency-free. You can host it in seconds on:
- **Netlify**: Drag and drop the `nail-n-lash-studio` folder into Netlify Drop.
- **Vercel**: Run `vercel deploy` or import the repository.
- **GitHub Pages**: Push to a GitHub repository and turn on GitHub Pages under repository settings.
- **cPanel / Hostinger**: Upload the files to `public_html`.
